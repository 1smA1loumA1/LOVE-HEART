# INFINITE LOVE

A cinematic, code-generated heart made from hundreds of multilingual expressions of love. Built with Python 3 and Tkinter Canvas; no image assets or third-party packages are used.

## Run

On Windows 11, install Python 3 from [python.org](https://www.python.org/downloads/windows/) and ensure **tcl/tk and IDLE** is selected in the installer. Then, from this folder:

```powershell
python main.py
```

The heart silhouette uses an implicit mathematical heart curve and randomized interior sampling. Words first gather from scattered positions, then breathe and shimmer as a softly pulsing shape. The settings panel adjusts heart scale, motion, particle count, theme, and an optional center message.

## Controls

- Pause / play: button or Space
- Restart: button
- Cycle palette: Theme button
- Fullscreen: button or F11; Escape exits
- Hide / show controls: ☰ button

Fonts fall back to system-installed Georgia and Segoe UI on Windows. Particle count is adjustable from 150 to 650. `assets/` is reserved for future additions; no static heart image is required or used.
